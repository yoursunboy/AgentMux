# Frontend Rules

- Frontend uses React + TypeScript.
- xterm.js renders real terminal output.
- Do not build a replacement chat UI for Claude.
- Keep Global Bar compact.
- Terminal occupies most of each project panel.
- Header and Prompt Bar remain fixed.
- Client scroll state is local.
- Grid, Focus, and Full Screen are presentation states only.
- Avoid enterprise-dashboard clutter.
- iPad landscape is a primary target.
- Project Manager must support Register/Open from nested collection folders.
